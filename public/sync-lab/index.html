Laboratoire faust-sync

Mesures pour l'algorithme de synchronisation (spécification, § 10) : ce que donnent les horloges audio de plusieurs fenêtres du navigateur sur une même carte son.

  1. Ferme les fenêtres de ce laboratoire encore ouvertes. Ouvre cette page dans deux fenêtres côte à côte (pas deux onglets d'une même fenêtre : un onglet caché a ses minuteries ralenties). Clique Démarrer dans chacune.
  2. Attends une minute : les lignes se remplissent. δ reste constant, ou dérive régulièrement si les deux fenêtres ne comptent pas leurs échantillons à la même vitesse.
  3. Clique Clics dans les deux fenêtres : chacune clique deux fois par seconde, la seconde 100 ms après la première (l'écart qui permet à l'enregistrement de les distinguer), alignées par δ (prédit par la droite de ses valeurs des 20 dernières secondes).
  4. Dans une fenêtre, Enregistrer : le micro intégré près des haut-parleurs suffit (le trajet acoustique est le même pour les deux clics), ou un bouclage (BlackHole, câble). L'écart mesuré, moins 100 ms, est l'erreur réelle.
  5. Copier le rapport dans chaque fenêtre, et colle-les dans la conversation. Refais-le après une dizaine de minutes.
  6. Pour écouter : écart 0 dans les deux fenêtres. Alignés, les deux clics n'en font qu'un ; décalés de quelques ms, ils se dédoublent.
